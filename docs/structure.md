# PLEX-34 STRUCTURE Workflow

The app can generate a STRUCTURE package for PLEX-34 and parse one uploaded STRUCTURE result file. It doesn't run the external STRUCTURE binary.

## Generated Package

After a VCF is uploaded and validated, the app can generate a zip package containing:

- `plex34_structure_input.txt`.
- `mainparams`.
- `extraparams`.

The package uses the PLEX-34 marker list, bundled population metadata, and vendored STRUCTURE parameter templates. Missing markers are recorded, marker order is preserved, and the generated artifact is temporary.

## Install STRUCTURE

Download STRUCTURE from the Pritchard Lab website:

<https://web.stanford.edu/group/pritchardlab/structure.html>

Install it according to the official STRUCTURE instructions for your system.

## Create a STRUCTURE Project

1. Open STRUCTURE.
2. Create a new project.
3. Choose a directory for the project.
4. Import or select the files generated by the app: `plex34_structure_input.txt`, `mainparams`, and `extraparams`.

## Run STRUCTURE Externally

Replace the paths below with the location of your STRUCTURE executable and extracted package files:

```bash
path_to_structure/structure \
    -i path_to_package/plex34_structure_input.txt \
    -m path_to_package/mainparams \
    -e path_to_package/extraparams \
    -o path_to_output/output.txt
```

Arguments:

- `path_to_structure/structure`: STRUCTURE executable.
- `-i`: generated `plex34_structure_input.txt`.
- `-m`: generated `mainparams`.
- `-e`: generated `extraparams`.
- `-o`: output file created by external STRUCTURE.

## Upload Result Output

After the external run finishes, return to the app and upload one `.txt` or `.out` STRUCTURE output file. The app extracts inferred ancestry sample rows, reads cluster probabilities, and displays the highest STRUCTURE cluster.

The parser doesn't promise a final ancestry interpretation beyond the uploaded STRUCTURE output. It also doesn't match PLEX-34 samples with HIrisPlex-S samples.
